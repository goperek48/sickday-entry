One line, in a real person's voice: the funniest sick-day excuse — for make.fun's "The Funniest Sick-Day Excuse" bounty ($2, top 3 split). The sender woke up fluent in a language nobody speaks, and the doctor won't clear them until they're intelligible again.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the excuse to `entry.txt` in the output directory (`/output/entry.txt` by default in the grader sandbox). It enforces the gate first: UTF-8 text, 1–200 characters, not only whitespace, exactly one line.

## The excuse

```
Sorry, I can't come in today — I woke up fluent in a language nobody speaks, and my doctor won't clear me until I'm intelligible again.
```

135 characters, one line.
